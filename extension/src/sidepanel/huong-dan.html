Khởi động Translation trên máy

Trang này nằm trong gói tiện ích — không gọi ra internet.
  1. Mở thư mục dự án Translation trong terminal, rồi chạy: 
    docker compose -f deploy/docker-compose.yml up -d
  2. Chờ tới khi API trả lời. Kiểm nhanh: 
    curl http://127.0.0.1:8010/healthz
    Thấy {"status":"ok"...} là API đã sống.
  3. Giao diện web app chạy ở http://127.0.0.1:5174 (bản docker) hoặc http://127.0.0.1:5173 (chạy npm run dev trong frontend/). Cổng thật đọc trong .env của dự án.
  4. Quay lại Side Panel, nhập đúng địa chỉ giao diện đó rồi bấm Lưu & kiểm tra kết nối.

Vẫn báo chưa kết nối?

Nếu web app mở được trong tab nhưng tiện ích vẫn báo chưa kết nối, gần như chắc chắn là máy chủ chưa cho tiện ích đọc dữ liệu (CORS). Mở Cài đặt kết nối của tiện ích để xem cách thêm ID tiện ích vào CORS_ALLOW_ORIGINS. Không làm bước đó thì tiện ích vẫn mở web app bình thường, chỉ là không hiện được trạng thái chapter.
