1. English Version — Chrome Web Store User Data Privacy Policy

This Privacy Policy explains how Dịch Truyện AI Tự Động — Comic, Manga & Webtoon Translator ("the Extension") and comic.io.vn ("we", "us", or "our") collect, use, handle, and protect user data in strict compliance with the Chrome Web Store Developer Program Policies.

1.1. Single Purpose & When Data is Processed

The Extension has a single purpose: detecting speech bubbles, erasing original text, and overlaying translated text onto comic, manga, manhwa, and webtoon images on the webpage the user is actively reading. The Extension remains completely dormant until explicitly triggered by the user (by clicking the "Translate" button in the popup or pressing the keyboard shortcut Alt+Q / Alt+S / Alt+A / Alt+W).

1.2. Data Collected & How It Is Used

  • Comic Images & Story Text (User-Initiated Only): When you trigger translation on a comic page, the Extension extracts only the comic image(s) on the active tab and transmits them securely over HTTPS (`TLS 1.2+`) to our translation API (https://comic.io.vn/api/v1/ / https://translation-api.vibe1.tinhgon.xyz) to perform Optical Character Recognition (OCR), speech bubble detection, and AI contextual translation.
  • Local Preferences (chrome.storage.local): The Extension stores your selected source language, target language, font style, translation engine mode, and optional account session token (`tr_live_...` or JWT) locally inside your browser using chrome.storage.local.
  • Optional Account Synchronization: If you sign in on https://comic.io.vn, your email address and remaining page quota are used solely to authenticate your requests and synchronize your translation balance across the Web Studio and Chrome Extension.

1.3. Chrome Permissions Justification

  • activeTab: Used to access the currently active tab when the user clicks the extension or presses the translation shortcut to capture and translate the comic image being viewed.
  • scripting: Used to inject the on-page translation overlay script (src/content/index.js) so translated speech bubbles are rendered directly over the comic images.
  • storage: Used to save user preferences (language pair, comic font, AI mode, and optional API/session token) locally in the browser.
  • <all_urls> (Host Permission): Required because users read comics, manga, and webtoons across thousands of independent scanlation and publisher websites and CDN image domains worldwide.

1.4. Data Retention, Sharing & Google Limited Use Disclosure

  • No Browsing History Tracking: We do NOT collect, log, or monitor your general web browsing history, search queries, form inputs, passwords, or payment card details.
  • No Sale of User Data: We do NOT sell, rent, license, or trade any user data to third parties, data brokers, or advertising networks.
  • Google Limited Use Compliance: The use of information received from Google APIs and Chrome Extension APIs adheres strictly to the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is never used for personalized advertising, creditworthiness lending, or unrelated analytics.
