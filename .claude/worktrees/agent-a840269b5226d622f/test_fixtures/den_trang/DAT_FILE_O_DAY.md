# Chỗ đặt trang manga đen trắng để đo E14

Thả file ảnh (`.jpg` / `.png`) vào **chính thư mục này**, rồi báo tôi tên file.

Đường dẫn đầy đủ trên workspace:

    ~/workspace/projects/Translation/test_fixtures/den_trang/

Thả xong tôi sẽ chạy:

1. Nhận diện khung chữ (M2) → xoá chữ (M4) → tính vùng an toàn (E14) trên đúng trang đó.
2. So từng vùng: nhận được hình hay lùi về dự phòng, kèm mã lý do.
3. Kiểm theo điểm ảnh xem khối chữ có nằm trọn trong bong bóng không.
4. Xuất ảnh chồng đường viền để nhìn tận mắt từng bong bóng.

Thư mục này **không đưa vào git** (ảnh có bản quyền) — xem `.gitignore`.
